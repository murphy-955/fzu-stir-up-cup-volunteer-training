# 转身检查长培训

## 转身检查长工作

依据《世界泳联竞赛规则（2026年2月生效）》游泳规则第2.7条，转身检查长（Chief Inspector of Turns）的职责如下：

1. 确保各转身检查员在比赛期间履行其职责，检查各个转身检查员是否正常工作；
2. 接收转身检查员上报的犯规并核实，犯规的最终裁定权在执行总裁判；
3. 每一组游进完成后，如存在犯规并经确认，需要立刻报告给执行总裁。

## 工作流程

1. 紧密关注运动员的转身技术是否存在问题
2. 接受转身检查员的犯规报告
3. 如果是接力，同样需要检查每位运动员的犯规
4. 如果比赛是50米，那就没什么事情了O^O

**注意：** 发令员吹出一声长哨后，也要起立，在打响发令枪后即可坐下
