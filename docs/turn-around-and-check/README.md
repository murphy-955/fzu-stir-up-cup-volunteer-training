# 转身检查培训

## 转身检查工作

依据《世界泳联竞赛规则（2026年2月生效）》游泳规则第2.8条，转身检查员（Inspectors of Turns）的职责如下：

1. 游泳池两端每条泳道各设1名转身检查员，确保运动员在出发后、每次转身及终点到达时遵守相关规则；
2. 检查管辖范围：
   - **出发端**：自出发信号发出起，至第一次划水动作完成为止（蛙泳为第二次划水动作完成）；
   - **每次转身**：自触壁前最后一次划水动作开始起，至转身后第一次划水动作完成为止（蛙泳为第二次划水动作完成）；
   - **终点端**：自触壁前最后一次划水动作开始起；
3. 接力比赛中，出发端转身检查员须判定下一棒运动员在前一棒队友触壁时是否仍与出发台保持接触；
4. 判断运动员转身是否犯规，将管辖范围内观察到的任何犯规（包括泳姿规则犯规）上报至[转身检查长](../turn-around-and-check-the-chief/README.md)，由执行总裁判最终裁定。

## 工作流程

1. 运动员距离岸边15米时，起立，走上游泳池边
2. 将身子探出去，检查是否犯规
3. 运动员转身完成，并开始蹬边后，回到座位上
4. 如果犯规，在 运动员道边后，需要上报至[转身检查长](../turn-around-and-check-the-chief/README.md)

**注意：** 发令员吹出一声长哨后，也要起立，在打响发令枪后即可坐下
