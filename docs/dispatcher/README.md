# 发令员培训

## 发令员工作

依据《世界泳联竞赛规则（2026年2月生效）》游泳规则第2.5条，发令员（Starter）的职责如下：

1. 自执行总裁判以伸展手臂的手势示意起，至比赛开始为止，对运动员拥有完全的控制权；
2. 在每组比赛开始时发出出发信号，保证运动员公平地开始比赛；
3. 发令时应站在距出发端约**5米**以内、计时员能看到和/或听到出发信号且运动员能听到信号的池侧位置；
4. 判定运动员出发时是否犯规（仅服从执行总裁判的决定）。如取消运动员比赛资格或录取资格，须经执行总裁判同意；
5. 判定出发是否公平；如出发不公平，应召回运动员重新出发；
6. 发现运动员延误比赛、蓄意不服从命令或在出发时有任何犯规行为时，应向执行总裁判报告，由执行总裁判决定是否取消该运动员的比赛资格。

## 发令流程

1. 听到[计时长](../time-keeper-leader/README.md)喊出**回表**，并等执行总裁确认本组成绩/犯规后，进行如下操作。
2. 1号发令员负责吹响**4声长哨+1声短哨**，等待运动员就位后向2号发令员**做出手势信号**。
3. 2号发令员收到手势信号后，喊”**各就位**“，待所有运动员身体稳定后**打响发令枪**。

## 可能犯规点

1. 2号发令员喊出”**各就位**“后运动员身体晃动（规则4.4：任何运动员在出发信号发出前开始出发，可被取消比赛资格）。
2. 若出发信号发出后才宣布犯规，比赛继续进行，犯规运动员在该组比赛结束后被取消资格；若在出发信号发出前宣布犯规，则不发出发信号，令其余运动员起立待命（"stand down please"），并由执行总裁判从长哨起重复出发程序。
