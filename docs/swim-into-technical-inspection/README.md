# 游进技术检查

## 游进技术检查工作

依据《世界泳联竞赛规则（2026年2月生效）》游泳规则第2.9条，游进技术检查员（Judges of Stroke）的职责如下：

1. 位于游泳池两侧，负责包干区域的运动员游进技术检查；
2. 确保运动员遵守该比赛项目指定泳姿的相关规则，并观察转身和终点到达情况，以协助转身检查员；
3. 如有犯规，待本组所有运动员完成比赛后，向[执行总裁](../executive-president/README.md)报告管辖范围内观察到的任何犯规（包括泳姿规则犯规）；
4. 在每组仰泳或混合泳比赛开始前，确保距两端池壁**5米**处的仰泳转身标志线安装到位。

## 工作流程

1. 1声长哨后，起立
2. 发令员发令后，跟随运动员，做技术检查
3. 如有犯规，待本组所有运动员完成比赛后，向[执行总裁](../executive-president/README.md)报告
