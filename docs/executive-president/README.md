# 执行总裁培训

## 执行总裁工作

依据《世界泳联竞赛规则（2026年2月生效）》游泳规则第2.3条，执行总裁判（Referee）的职责如下：

1. 对比赛中的所有技术官员拥有全面的管理权和权威，批准他们的岗位分配，并就与比赛项目相关的所有特殊事项或规定对他们进行指导；严格执行竞赛规程和竞赛规则，解决比赛中的有关问题，并可决定规则中未详尽或没有明文规定的事项，但不能修改规程和规则；
2. 可在比赛的任何阶段干预比赛，裁定比赛过程中的各种异议，以保证规程和规则得以执行；
3. 当终点裁判员所判定的名次与计时员计取的成绩不一致时，由当场执行总裁判决定名次；
4. 确保比赛顺利进行所需的所有技术官员在比赛期间各就各位，可随时指派替补裁判员上岗工作，在必要时有权撤换缺席、不能履职或不称职的裁判员；
5. 根据自己的观察或其他裁判员的报告，有权取消犯规运动员的比赛资格或录取资格；出发抢跳犯规须由发令员和执行总裁判双方观察确认（2026年规则明确：双方无需达成一致意见，且在有自动计时装置时应回看录像核实）；犯规一经确认，报告的裁判员须填写并签署犯规卡，注明项目、泳道和犯规事实；
6. 技术代表授权的执行总裁判应于比赛前检查场地、器材是否符合规则的规定；
7. 当场执行总裁判在每组比赛开始时，组织运动员出发：先以**连续短哨**示意运动员做好准备，再以**一声长哨**示意运动员上出发台（仰泳项目为入水/就位），随后以**伸展手臂的手势**将运动员交由发令员控制，手臂保持伸展直至出发信号发出；
8. 接力比赛中，指派技术官员判定下一名运动员的双脚在前一名队友触壁完成本棒时是否仍与出发台保持接触；
9. 各项比赛成绩须经当场执行总裁判签名确认。
