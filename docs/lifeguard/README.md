# 救生员培训

## 救生员工作

依据《世界泳联竞赛规则（2026年2月生效）》第一部分第8.8.6、8.8.7、8.10.2条及游泳规则第16.4条，救生员（Lifeguard）的职责如下：

1. 确保运动员安全完赛；每个游泳池至少配备**2名**救生员，并根据运动员人数按比例增加；
2. 在所有训练和比赛时段驻守池边并清晰标识，负责水中遇险运动员的施救；须具备深水救援经验，熟悉针对各类潜在医疗事件的水中救援，并每日演练运动员水中救捞技能（注意泳道线可能阻碍接近运动员，影响合适的施救起水点）；
3. 遇险运动员**有意识**时：让其抓住浮具，在救生员协助下牵引至池边；**昏迷或无法抓握浮具**时：须先将其稳定在浮具上再救捞出水；
4. 出水后在池边进行初步评估，识别需立即处置的危及生命状况，重点判断是否需要心肺复苏（CPR）和颈椎固定，情况稳定后转运至医疗点进一步评估。

## 救生员工作流程

1. 比赛开始后，坐在专门的救生椅上时刻注意场上运动员状态（特别注意**水平不高**的运动员）
2. 如果观察到运动员有明显的挣扎动作，立刻吹哨子。就近下水，将运动员的手达到水线上
3. 如果运动员昏迷，立即启动应急预案，呼叫医疗人员，并做CPR。
4. 执行总裁有权宣布暂停比赛
