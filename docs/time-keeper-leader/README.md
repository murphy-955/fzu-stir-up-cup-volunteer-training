# 计时长培训

## 计时长工作

依据《世界泳联竞赛规则（2026年2月生效）》游泳规则第2.10条，计时长（Chief Timekeeper）的职责如下：

1. 为所有计时员安排座位位置及其负责的泳道；人工计时条件下每条泳道设2名计时员，另设至少1名替补计时员（用于替换比赛中秒表失灵或因其他原因无法计时的计时员）；
2. 必须记录每组比赛第一名的成绩；
3. 向各泳道计时员收集记录成绩的成绩卡，必要时检查其秒表；
4. 在成绩卡上记录各泳道的正式成绩，如果有犯规交由执行总裁确认；
5. 执行总裁确认后，喊**回表**。

## 计时长工作流程

1. 从8道到1道依次收集成绩表
2. 如果有计时员报告**犯规**交由执行总裁确认
3. 执行总裁确认后，喊**回表**

**注意：** 发令员吹出一声长哨后，也要起立，在打响发令枪后即可坐下
