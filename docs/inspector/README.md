# 检录人员

## 检录人员工作

依据《世界泳联竞赛规则（2026年2月生效）》游泳规则第2.6条，检录员（Call Room Judges）的职责如下：

1. 负责进行检录工作，在每组比赛前召集运动员；
2. 发现可能存在泳衣和/或广告标识违规，或运动员被点名时未到场的情况，应向检录长报告；泳衣/广告违规由检录长认定后报告执行总裁判；
3. 将运动员带入场地。

## 检录人员工作流程

1. 2名检录人员按照秩序册进行检
2. 1名检录人员将运动员带入场地
